# TOMIC BAU – Website-Vorschau

Entwurf der Website für TOMIC BAU (Asphalt- und Kabelbau).

## Stand
- `index.html`: hochgeladen, enthält die Startseite, Leistungen, Referenzgalerie und ein Demo-Anfrageformular.
- `assets/`: **Bilddateien fehlen noch**; sie sind im Paket `TOMIC_BAU_Website_V2.zip` enthalten.
- Firmendaten, Impressum und Datenschutz müssen vor regulärer Veröffentlichung ergänzt werden.
- Die Kontaktanfrage wird nicht versendet.

## Bilder ergänzen
1. Lokales Paket `TOMIC_BAU_Website_V2.zip` entpacken.
2. Im GitHub-Repository den Ordner `assets` öffnen.
3. `Add file` > `Upload files` und alle 14 `.webp`-Dateien aus `tomic-bau-website/assets/` hochladen.
4. `Commit changes` bestätigen.

## Vorschau mit GitHub Pages
Nach vollständigem Bild-Upload unter `Settings > Pages` die Quelle `Deploy from a branch`, Branch `main`, Folder `/(root)` wählen und speichern.
Die Vorschau wird dann unter https://dlukic1312.github.io/Tomic-Bau/ abrufbar.

Achtung: GitHub Pages ist öffentlich. Fotos mit erkennbaren Personen, Kennzeichen oder fremden Logos vor Freigabe prüfen.
